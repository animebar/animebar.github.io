01 About

I'm a software engineer based in Berlin, working at AWS on developer tooling. Most of my day is spent on Amazon Q and on building MCP servers that let AI agents work safely against real AWS infrastructure.

I like problems where correctness matters and the feedback loop is slow — the ones you can't brute-force. Lately that's meant a lot of time on agent evaluation, benchmarking, and making tools that other engineers actually want to use.
